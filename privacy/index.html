Personal Data We Collect

We collect account and authentication data such as email address, user identifier (UUID), and authentication tokens. We collect profile information including phone number, verification status, preferred marketplaces, city preferences, and account timestamps.

For phone verification, we process phone numbers and one-time password verification events via Twilio. For payments and billing, we process subscription status and purchase metadata through Apple In-App Purchases (for iOS). We collect credit balances linked to user accounts.

We collect item data including uploaded images stored in cloud storage, item details, AI-generated outputs such as pricing and marketplace suggestions, structured JSON results, and analysis records.

If you opt in to notifications, we process push notification tokens (for example, Expo push tokens) and related delivery metadata to send you service notifications.

For marketplace integrations, we process OAuth tokens, identifiers, listing metadata, and integration status. We also process limited technical information such as timestamps, request metadata, and error logs for security and debugging.

How We Use Personal Data

We use personal data to operate and provide the Service, authenticate users, prevent misuse, process payments, manage credits, perform AI analysis, enable marketplace integrations, and maintain security and reliability.
